✨ نظرة عامة

موقع Portfolio شخصي يعرض الملف المهني لـ علي أحمد القاسم — طالب هندسة معلوماتية (مسار هندسة البرمجيات) ومطوّر واجهات أمامية متخصص في React و Tailwind CSS.

يعتمد التصميم على ثيم "Blueprint / Terminal": خلفية كحلية عميقة بشبكة تقنية خفيفة وجسيمات متحركة على Canvas، مع طرفية تفاعلية تكتب بيانات المطوّر حرفًا حرفًا في الواجهة الرئيسية.

🧩 المزايا

🌗 وضع ليلي / نهاري مع حفظ التفضيل في localStorage
💻 طرفية تفاعلية في الـ Hero تحاكي سطر الأوامر
⌨️ Typewriter Effect للمسمّى الوظيفي
🕸️ شبكة جسيمات متحركة على Canvas مع خطوط اتصال
📜 Scroll Reveal Animations عبر IntersectionObserver
🔢 عدّادات متحركة لقسم الإنجازات
🧭 Scroll Spy لتتبع القسم النشط في شريط التنقّل
📱 Responsive بالكامل — Mobile First Design
🖨️ تحميل السيرة الذاتية عبر الطباعة / حفظ PDF
✉️ نموذج تواصل يعمل عبر mailto
♿ Accessibility: Semantic HTML، ARIA، Skip Link، دعم prefers-reduced-motion
🔍 SEO: Meta Tags + Schema.org (JSON-LD)
🛡️ Progressive Enhancement: المحتوى يظهر بالكامل حتى لو تعطّل JavaScript

🛠️ التقنيات

| التقنية | الاستخدام |
|---|---|
| HTML5 | هيكل دلالي (Semantic) مع دعم RTL كامل |
| CSS3 | Custom Properties، Grid/Flexbox، Animations، Dark/Light Themes |
| Vanilla JavaScript | كل التفاعلات بدون أي مكتبات خارجية |
| Canvas API | خلفية الجسيمات المتحركة |
| IntersectionObserver | حركات الكشف والعدّادات والـ Scroll Spy |
| Fontsource CDN | خطوط Noto Kufi Arabic + IBM Plex Sans Arabic + IBM Plex Mono |

⚙️ التشغيل محليًا
bash
1) استنساخ المستودع
git clone https://github.com/ali-alhumse/portfolio.git
cd portfolio

2) فتح الموقع — أحد الخيارين:
python -m http.server 8000        # ثم افتح http://localhost:8000
أو استخدم إضافة Live Server في VS Code

لا يحتاج المشروع أي تثبيت أو Build — افتح index.html مباشرة.
