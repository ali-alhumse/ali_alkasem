# Ali Ahmad Alkasem | Portfolio

موقع شخصي يعرض السيرة الذاتية والمشاريع والخبرات التقنية لعلي أحمد القاسم، طالب هندسة معلوماتية في مسار هندسة البرمجيات ومطوّر واجهات أمامية.

يقدّم الموقع المعلومات المهنية ضمن واجهة عربية متجاوبة، مع دعم كامل لاتجاه الكتابة من اليمين إلى اليسار، ووضعين للعرض، ومعرض تفاعلي لصور المشاريع.

## حالة المشروع

هذا المستودع مخصّص للعرض والاطلاع فقط. جميع محتويات الموقع وتصاميمه ونصوصه محفوظة الحقوق، ولا يُسمح بنسخها أو إعادة استخدامها أو توزيعها دون إذن مسبق من صاحبها.

## محتوى الموقع

- نبذة مهنية ومعلومات التواصل.
- المهارات التقنية والأدوات المستخدمة.
- الخبرات والأنشطة ضمن خط زمني.
- مشاريع واجهات الويب، ومنها بوابة طلاب جامعة الرواد، ونظام إدارة المنتجات، ومنصة طمّني للرعاية الصحية.
- التعليم والشهادات والإنجازات.
- معرض صور تفاعلي لواجهات المشاريع.

## التقنيات

| التقنية              | الاستخدام                                                        |
| -------------------- | ---------------------------------------------------------------- |
| HTML5                | بناء هيكل دلالي يدعم اللغة العربية واتجاه RTL                    |
| CSS3                 | التخطيط المتجاوب، السمات، الحركات، والوضعان الليلي والنهاري      |
| Vanilla JavaScript   | التفاعلات، التنقل، الطرفية، العدادات، والنماذج                   |
| Canvas API           | رسم خلفية الجسيمات وخطوط الاتصال                                 |
| IntersectionObserver | تشغيل الحركات والعدادات عند ظهور العناصر                         |
| Fontsource CDN       | تحميل خطوط Noto Kufi Arabic وIBM Plex Sans Arabic وIBM Plex Mono |

لا يعتمد الموقع على أطر عمل أو حزم بناء خارجية.

## عن المطوّر

**Ali Ahmad Alkasem** مطوّر واجهات أمامية يركّز على بناء واجهات واضحة ومتجاوبة باستخدام React وTailwind CSS وJavaScript. يدرس هندسة المعلوماتية في السنة الثالثة، مسار هندسة البرمجيات، في جامعة الرواد للعلوم والتقنية.

من المشاريع المعروضة في الموقع:

- **بوابة طلاب جامعة الرواد:** منصة تجمع المواد والملخصات والامتحانات السابقة والفيديوهات التعليمية.
- **نظام إدارة منتجات التجارة الإلكترونية:** نظام CRUD لإدخال المنتجات وإدارتها مع حساب السعر والخصم والضريبة.
- **طمّني:** منصة رعاية صحية طُوّرت ضمن فريق، وتوفّر واجهات لتسجيل الدخول، والبحث عن الصيدليات المناوبة، وحجز المواعيد، وطرح الأسئلة الطبية. أُنجز المشروع في عام 2026، ويمكن العثور على اسم `Ali Alhumse` في تبويب المطورين داخل فوتر المنصة.
